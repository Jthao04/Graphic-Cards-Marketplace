## Description

A marketplace where a user is able to sell new or used graphic cards and browse all graphic cards that all users have posted to the marketplace. The different graphic cards categories/brands that are available to be sold are Nvidia, Intel, and AMD. The graphic cards will display data such as the name of the graphic card, the price, the condition, and the category, description of the card, and the seller's email. The user that is logged into the marketplace will also be able to view their own postings through the dashboard button on the navigation bar.

## Installation

Clone the repository and make sure all keys/passwords are set up in the .env file in the server side (backend) and client side (frontend). Using MongoDB, create a database so all users and listings can be stored in the database. Next open the terminal in the backend preferably in the package.json and "type npm i". After type "npm run dev" to start up port in the backend and it should tell that the server is running on a specific port and that MongoDB is connected. Next open up another terminal in the frontend prefereably in the package.json and type "npm run dev" as well and a port should open and redirect you to a webpage. Register and login as a user and get ready to sell and browse graphic cards in the marketplace!

## Usage

Use this application to sell used and new graphic cards and browse not only your own listings, but also everyone else who has created listings within the marketplace.

## Tests

Run "npm run dev" in the server side (backend) to have the port run and then MongoDB will be connected to the database. Then run "npm run dev" in the client side (frontend) to have it's own port open and a web page will run. Since the port in the backend is running, the frontend will be able to run the neccessary functions such as selling graphic cards, have the user see their own listings and browse all listings for graphic cards within the marketplace.
